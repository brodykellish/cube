# DAG Architecture Refactor

## Overview

Refactor the DAG system to clearly separate concerns:

- **`dag.py`**: Manages all connection logic, node topology, input/output mapping, and feedback configuration
- **`dag_renderer.py`**: Stateless utility that walks the DAG and orchestrates OpenGL rendering

## Key Architectural Changes

### 1. Connection Model in DAG

The DAG will track explicit input/output channel connections:

```python
# New connection structure
Connection = {
    source_node: Node,
    source_output: int,  # Always 0 for now (single output)
    target_node: Node,
    target_input_channel: int,  # iChannel0, iChannel1, etc.
    connection_type: 'node_output' | 'feedback'
}
```

Note: External sources (video, images, webcam) are implemented as special node types, so their outputs connect like any other node output. The distinction between "external" and "node" is at the node type level, not the connection level.

### 2. Node Input Channel Configuration

Nodes will support variable input channels with metadata:

- **External sources**: Video files, images, webcam (via special source nodes)
- **Node outputs**: Output texture from another node
- **Feedback**: Internal node feedback (stored as node metadata, not DAG connection)

### 3. Shader Config Files

Create YAML config files alongside shader files (e.g., `shader.glsl` → `shader.yml`):

```yaml
# shader.yml
inputs:
 - channel: 0
    name: iChannel0
    type: node_output  # or 'external', 'feedback'
    required: true
 - channel: 1
    name: iChannel1
    type: external
    required: false
feedback:
  enabled: false
  channel: 0  # Which input channel receives feedback
```

### 4. External Source Nodes

Create new node types for external data:

- `VideoSourceNode`: Loads video files
- `ImageSourceNode`: Loads static images
- `WebcamSourceNode`: Captures webcam frames

These connect like regular nodes but have special texture update logic.

### 5. Feedback as Node Metadata

Feedback is internal to nodes (not a DAG cycle):

- Nodes have `feedback_config` dict specifying which input channel receives their own output
- DAG remains acyclic
- Renderer handles feedback by binding node's output texture to its own input channel

## Data Structures

### Connection

```python
@dataclass
class Connection:
    source_node: Node
    target_node: Node
    target_input_channel: int  # 0-3 for iChannel0-3
    connection_type: Literal['node_output', 'external', 'feedback']
```

### InputChannelConfig

```python
@dataclass
class InputChannelConfig:
    channel: int
    name: str  # e.g., 'iChannel0'
    type: Literal['node_output', 'external', 'feedback']
    required: bool
    source: Optional[Node] = None  # Set by DAG connections
```

### FeedbackConfig

```python
@dataclass
class FeedbackConfig:
    enabled: bool
    input_channel: int  # Which input receives feedback
    delay_frames: int = 0  # Optional frame delay for feedback
```
